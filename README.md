# pcge-peru-ts

Biblioteca TypeScript para consultar el Plan Contable General Empresarial del Perú.

La implementación toma como referencia los datos y la trazabilidad de [pcge-peru](https://github.com/mat-l-dev/pcge-peru), manteniendo separadas las ediciones 2019 y 2026.

## Estado

Implementación inicial en desarrollo. El paquete todavía no está publicado en npm.
